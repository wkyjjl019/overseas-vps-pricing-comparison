按访客来源分流的老规则依然适用：访客以电信为主，优先看洛杉矶的 CN2 GIA；联通用户对东京节点更敏感；移动用户三个方向都能用，新加坡性价比通常更好。AVA 是否提供上述任何一种线路，官网没有答案，这是下单前必须问清的第一件事。

## 只写在条款里的四个限制

**用折扣码下的单不退款。** 退款政策和服务条款都写明了这一条：使用促销代码或折扣购买的服务不予退款，促销码降低了套餐价格的订单被视为最终订单。这句话的实际含义是，你想要 30 天退款保障，第一单就别填优惠码。先按原价买一个月测，觉得可以再考虑后续怎么续。

**30 天退款只给首次账户。** 原文的口径是只有首次开通的 hosting 账户才有资格，之前买过同类套餐并退款成功，再买同类别就不能再退。同一类别退第二次这条路是关的。

**退款可能要身份验证。** 条款里写明支付网关有时会要求提供护照 ID，客户不愿提供时，商家保留不退款的权利。这不是必然流程，但要有心理准备。

**VPS Nano 的 25 端口关闭。** 页面上用红叉标了出来，意味着这台机器不能直接发邮件。其余套餐没有这条标注，是否开放 25 端口同样建议开工单确认。

关于流量，"Unlimited Bandwidth" 是全系标注，但官网没有公开公平使用（fair use）的具体阈值，也没有写超量之后是限速到多少还是停机。其他商家这类条款通常长什么样可以参考：CCIHosting 写的是不限量但仍受公平使用和端口速率约束，持续异常用量会被限制；ByteVirt 的做法是超量后端口限速到 1Mbps。AVA 属于哪一种，条款里查不到，只能问。

## 常见问题

**海外 VPS 要备案吗？**
ICP 备案针对的是中国大陆境内接入的网站，机房在境外不涉及这套流程。前提是确认机房确实在境外，而 AVA 的机房位置官网没公开，这一条得先问清楚。

**€2 的 Start 款能干什么？**
1 核 1GB、15GB NVMe，跑静态站、轻量 Docker 容器、Telegram bot、爬虫节点、个人代理都够。跑 MySQL 加 WooCommerce 这种组合会明显吃紧，内存先不够。

**用优惠码买了还能退吗？**
不能。这是退款政策里写得最硬的一条，折扣订单视为最终订单。

**超流量会怎样？**
官网标不限流量，没有公开限速阈值和处理规则。下单前问客服要一个明确答复。

**多久能开通？**
条款写付款后通常立即激活，涉及人工核验的情况最长 24–48 小时，访问凭证发到注册邮箱。
